# Журнал переглянутого — налаштування

Два файли:
- `index.html` — сама сторінка (нічого міняти не треба)
- `movies.json` — список фільмів, саме тут ти будеш додавати нові записи

## Крок 1 — створи репозиторій на GitHub

1. Зайди на github.com → **New repository**
2. Назви його, наприклад, `movies` (назва вплине на посилання)
3. Постав "Public", без README (у нас уже є свій)
4. Створи репозиторій

## Крок 2 — заливаєш файли

Найпростіше — прямо у браузері:
1. Відкрий свій новий репозиторій → **Add file → Upload files**
2. Перетягни туди `index.html` і `movies.json`
3. Commit changes

## Крок 3 — вмикаєш GitHub Pages

1. У репозиторії: **Settings → Pages**
2. У "Branch" вибери `main` і папку `/root`, тисни **Save**
3. Через хвилину-дві GitHub видасть посилання виду:
   `https://<твій_нікнейм>.github.io/movies/`

Це посилання і кидаєш у Discord/Telegram/опис каналу. Працює завжди, незалежно від того, чи ти в мережі, чи ввімкнений чат.

## Як додати новий фільм

Відкрий `movies.json` прямо на GitHub (натисни на файл → значок олівця "Edit"), додай новий об'єкт у масив за зразком:

```json
{
  "title": "Назва фільму",
  "year": 2024,
  "genre": "Жанр",
  "watched": "2026-08-29",
  "rating": 5,
  "note": "Коротка нотатка про перегляд",
  "poster": "https://посилання-на-постер.jpg"
}
```

`rating` — від 0 до 5, показується бейджем зі зіркою на постері. `genre` можна вигадувати свій — фільтри на сторінці збираються з даних автоматично. `poster` — пряме посилання на картинку (постер); якщо залишити порожнім `""`, замість картинки покажеться плитка з назвою фільму.

Де взяти посилання на постер: відкрий сторінку фільму (наприклад на themoviedb.org чи будь-якому кіносайті), клацни правою кнопкою по постеру → "Копіювати адресу зображення" — і встав це посилання в поле `poster`.

Збережеш зміни (Commit changes) — сторінка оновиться сама протягом хвилини, перезавантажувати нічого не треба.

## Далі, якщо захочеш автоматизувати

Коли набридне редагувати вручну, цей же `movies.json` можна дописувати автоматично через Streamer.bot: команда для тебе на кшталт `!додайфільм <назва>` через GitHub API комітила б новий запис прямо в репозиторій. Скажи, якщо захочеш це зробити — налаштуємо окремо.
