# Сьогодні дивимось — налаштування

Сайт складається з восьми файлів:

- **`index.html`** — головна: карусель фільмів (сьогодні по центру, ліворуч переглянуті, праворуч заплановані)
- **`archive.html`** — повний архів переглянутого з пошуком і фільтрами по жанру
- **`movie.html`** — сторінка конкретного фільму: постер, опис, оцінка, реакції глядачів, коментарі. Відкривається кліком на будь-яку картку на головній чи в архіві
- **`my-orders.html`** — для глядачів: список фільмів, які саме вони замовили (видно після входу через Twitch)
- **`add-movie.html`** — адмінка для тебе: форма додавання фільму, яка сама комітить у `movies.json` на GitHub (без ручного редагування файлу)
- **`movies.json`** — дані про фільми, спільні для всіх сторінок
- **`common.css`** / **`common.js`** — спільні стилі та код (включно з налаштуваннями Firebase та Twitch-логіном), підключаються до кожної сторінки

Заливаєш усі файли на GitHub разом, з однаковою структурою папок (усі в корені репозиторію).

## Вхід через Twitch

На кожній сторінці зверху є кнопка "Увійти через Twitch". Після входу:

- у коментарях ім'я підставляється автоматично (замість поля вручну)
- з'являється лінк **"Мої замовлення"** — фільми, де `orderedBy` в `movies.json` збігається з Twitch-логіном глядача
- якщо зайшов саме **ти** (логін `yarosfactory`), з'являється додатковий лінк **"➕ Додати фільм"** на адмінку

Це не система безпеки в собі — вона просто ховає лінк на адмінку від усіх, крім тебе. Реальний захист адмінки — той GitHub-токен (без нього фільм однаково не закомітиться), Twitch-логін лише прибирає зайве з інтерфейсу.

### Одноразове налаштування — Twitch-застосунок

1. Зайди на **dev.twitch.tv/console/apps** (увійди своїм акаунтом yarosfactory) → **Register Your Application**
2. **Name** — будь-яка (наприклад `yarosfactory-movies`)
3. **OAuth Redirect URLs** → додай точну адресу своєї головної сторінки, наприклад `https://yarosfactory-twitch.github.io/movies/index.html`
4. **Category** → обери "Website Integration"
5. **Create** → відкрий застосунок → скопіюй **Client ID**
6. Відкрий `common.js`, знайди рядок `const TWITCH_CLIENT_ID = "ВСТАВ_СЮДИ_TWITCH_CLIENT_ID";` і встав туди своє значення
7. Переконайся, що рядок `const TWITCH_OWNER_LOGIN = "yarosfactory";` збігається з твоїм реальним Twitch-логіном

Client ID (на відміну від токенів) не секретний — його можна спокійно тримати у відкритому коді, так само роблять всі сайти з "Увійти через Twitch".

## Адмінка для додавання фільмів (`add-movie.html`)

Відкривай `https://<нік>.github.io/<репозиторій>/add-movie.html` — це сторінка тільки для тебе (нікуди з сайту на неї лінку немає для всіх, крім тебе — з'являється сама, коли заходиш через Twitch). Заповнюєш форму → тиснеш "Додати фільм на сайт" → фільм одразу комітиться в `movies.json`, сайт оновиться сам за хвилину.

### Одноразове налаштування — GitHub-токен

1. Зайди на **github.com → фото профілю (справа зверху) → Settings**
2. Внизу лівого меню: **Developer settings**
3. **Personal access tokens → Fine-grained tokens → Generate new token**
4. Дай назву (наприклад `movies-admin`), термін дії — на свій розсуд (можна "No expiration")
5. **Repository access** → "Only select repositories" → вибери свій репозиторій із сайтом
6. **Permissions → Repository permissions → Contents** → постав **"Read and write"**
7. **Generate token** — скопіюй токен (він показується один раз!)
8. Встав його в поле "Personal Access Token" на сторінці `add-movie.html` — далі він зберігається в цьому браузері, вводити повторно не треба

Токен діє тільки на той репозиторій, який ти обрав на кроці 5 — навіть якщо хтось його побачить, більше нічого зламати ним не можна.

## Як це працює

Статус кожного фільму визначається автоматично за полем `watched` (датою):

- дата **сьогоднішня** → фільм показується по центру каруселі як "Сьогодні"
- дата **в минулому** → фільм вважається переглянутим, показується ліворуч на головній і в архіві (потрібен `rating`)
- дата **в майбутньому** → фільм вважається запланованим, показується праворуч на головній (оцінку `rating` можна не вказувати)
- якщо на сьогодні **немає жодного фільму** з такою датою — під каруселлю з'явиться повідомлення "На жаль, сьогодні нічого не заплановано" з посиланням на твій Twitch

Карусель на головній гортається свайпом (на телефоні чи тачпаді) або стрілками. Клік на будь-яку картку фільму — і на каруселі, і в архіві — відкриває окрему сторінку цього фільму (`movie.html`) з описом, оцінкою, реакціями та коментарями глядачів.

## Як додати фільм

Відкрий `movies.json` на GitHub (значок олівця "Edit"), додай новий об'єкт у масив:

```json
{
  "title": "Назва фільму",
  "year": 2024,
  "genre": ["Комедія", "Драма"],
  "watched": "2026-08-29",
  "rating": 8,
  "note": "Опис фільму — показується на його окремій сторінці",
  "poster": "https://посилання-на-постер.jpg"
}
```

- `watched` — дата у форматі РРРР-ММ-ДД. Онови це поле на сьогоднішню дату, коли хочеш анонсувати "сьогоднішній" фільм.
- `genre` — один жанр рядком (`"Комедія"`) або кілька в масиві (`["Комедія", "Драма"]`) — фільтри в архіві й сторінка фільму підхоплять усі.
- `rating` — від 0 до 10. Для запланованих (майбутня дата) можна взагалі прибрати це поле.
- `note` — опис/нотатка, показується на сторінці фільму (`movie.html`), під оцінкою.
- `orderedBy` — необов'язково. Twitch-юзернейм глядача, який замовив фільм (той, що після `twitch.tv/`) — показується на сторінці фільму як клікабельне посилання на його канал ("Замовив(ла): нікнейм"). Якщо не вказати, рядок просто не показується.
- `poster` — пряме посилання на картинку. Порожній рядок `""` — покаже плитку з назвою замість фото.
  Де взяти посилання: відкрий сторінку фільму (наприклад на themoviedb.org), клацни правою кнопкою по постеру → "Копіювати адресу зображення".
- `id` — необов'язково. Якщо не вказати, генерується автоматично з назви. Якщо колись зміниш `title` фільму, який уже має коментарі/реакції, вкажи `id` вручну (будь-яке унікальне слово латиницею), щоб не втратити прив'язані до нього коментарі.

Збережеш зміни (Commit changes) — усі сторінки оновляться самі протягом хвилини.

В архіві (`archive.html`) є перемикач сортування поруч із пошуком: "Спочатку нові" (за датою перегляду, за замовчуванням), "За оцінкою" (від найвищої чи найнижчої) або "За роком" (від старих фільмів до нових, за роком випуску `year`).

## Оцінка, реакції та коментарі глядачів (Firebase)

На сторінці кожного фільму (`movie.html`) — власна оцінка глядачів (1-10, як середня по всіх, хто оцінив), емоджі-реакції (🔥❤️😂😢🤢) та коментарі. Оскільки GitHub Pages сам по собі нічого не зберігає, це працює через безкоштовний Firebase (Google).

Конфіг Firebase уже вставлено в `common.js` (в одному місці для всіх сторінок) — якщо колись знадобиться змінити проєкт, онови його там.

Глядач може поставити свою оцінку 1-10 (кнопки під середньою оцінкою) і змінити її пізніше, натиснувши інше число — своя попередня оцінка запам'ятовується в браузері глядача, а середнє перераховується автоматично для всіх.

### Правила безпеки Firestore

У консолі Firebase: **Firestore Database → Rules**, встав:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /reactions/{movieId} {
      allow read: if true;
      allow write: if request.resource.data.keys().hasAny(['fire','heart','laugh','sad','sick','ratingSum','ratingCount']);

      match /comments/{commentId} {
        allow read: if true;
        allow create: if request.resource.data.text is string
                       && request.resource.data.text.size() > 0
                       && request.resource.data.text.size() < 500
                       && request.resource.data.name is string;
        allow update, delete: if false;
      }
    }

    match /suggestions/{suggestionId} {
      allow read: if true;
      allow create: if request.resource.data.status == 'pending'
                     && request.resource.data.raw is string
                     && request.resource.data.raw.size() > 0
                     && request.resource.data.raw.size() < 300
                     && request.resource.data.submittedBy is string;
      allow update, delete: if true;
    }
  }
}
```

Натисни **Publish**. Якщо ти вже налаштовував правила раніше (без `ratingSum`/`ratingCount` та `suggestions`) — обов'язково онови й опублікуй їх заново.

## Побажання глядачів (`wishlist.html`)

Будь-хто, хто зайшов через Twitch, може на цій сторінці запропонувати фільм — вставивши посилання або написавши назву й рік. Ти (як `yarosfactory`) бачиш там же чергу на модерацію: для кожної пропозиції вводиш назву/рік/постер і тиснеш "Схвалити" (стає видимою всім) або "Видалити".

Схвалені пропозиції без постера показуються простим списком (назва + хто хоче), а з постером — картками. На кожній є кнопка **"Опублікувати →"** (видно тільки тобі) — переносить на `add-movie.html` з уже заповненою назвою, роком і постером (дату й замовника вписуєш сам). Після успішного збереження фільму ця пропозиція сама зникає зі списку побажань.

### Модерація

Коментарі не можна редагувати чи видаляти з сайту (навмисно, щоб ніхто не підчистив чужі). Видалити недоречний коментар: Firebase Console → Firestore Database → Data → колекція `reactions` → документ фільму → підколекція `comments` → видалити потрібний запис.

## Хостинг (GitHub Pages)

1. `github.com/new` → назви репозиторій → Public → Create repository (без README/gitignore/license)
2. У репозиторії: **Add file → Upload files** → залий усі файли з цієї папки → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `root` → **Save**
4. Через хвилину сайт буде за адресою `https://<нік>.github.io/<репозиторій>/`

## Далі, якщо захочеш автоматизувати

Коли набридне редагувати вручну, `movies.json` можна дописувати автоматично через Streamer.bot: команда типу `!сьогодні <назва>` через GitHub API комітила б новий запис прямо в репозиторій. Скажи, якщо захочеш це зробити — налаштуємо окремо.
