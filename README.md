# Сьогодні дивимось — налаштування

Сайт складається з п'яти файлів:

- **`index.html`** — головна: карусель фільмів (сьогодні по центру, ліворуч переглянуті, праворуч заплановані)
- **`archive.html`** — повний архів переглянутого з пошуком і фільтрами по жанру
- **`movie.html`** — сторінка конкретного фільму: постер, опис, оцінка, реакції глядачів, коментарі. Відкривається кліком на будь-яку картку на головній чи в архіві
- **`movies.json`** — дані про фільми, спільні для всіх сторінок
- **`common.css`** / **`common.js`** — спільні стилі та код (включно з налаштуваннями Firebase), підключаються до кожної сторінки

Заливаєш усі файли на GitHub разом, з однаковою структурою папок (усі в корені репозиторію).

## Як це працює

Статус кожного фільму визначається автоматично за полем `watched` (датою):

- дата **сьогоднішня** → фільм показується по центру каруселі як "Сьогодні"
- дата **в минулому** → фільм вважається переглянутим, показується ліворуч на головній і в архіві (потрібен `rating`)
- дата **в майбутньому** → фільм вважається запланованим, показується праворуч на головній (оцінку `rating` можна не вказувати)
- якщо на сьогодні **немає жодного фільму** з такою датою — під каруселлю з'явиться повідомлення "На жаль, сьогодні нічого не заплановано" з посиланням на твій Twitch

Карусель на головній гортається свайпом (на телефоні чи тачпаді) або стрілками. Клік на будь-яку картку фільму — і на каруселі, і в архіві — відкриває окрему сторінку цього фільму (`movie.html`) з описом, оцінкою, реакціями та коментарями глядачів.

## Як додати фільм

Відкрий `movies.json` на GitHub (значок олівця "Edit"), додай новий об'єкт у масив:

```json
{
  "title": "Назва фільму",
  "year": 2024,
  "genre": "Жанр",
  "watched": "2026-08-29",
  "rating": 5,
  "note": "Опис фільму — показується на його окремій сторінці",
  "poster": "https://посилання-на-постер.jpg"
}
```

- `watched` — дата у форматі РРРР-ММ-ДД. Онови це поле на сьогоднішню дату, коли хочеш анонсувати "сьогоднішній" фільм.
- `rating` — від 0 до 5. Для запланованих (майбутня дата) можна взагалі прибрати це поле.
- `note` — опис/нотатка, показується на сторінці фільму (`movie.html`), під оцінкою.
- `poster` — пряме посилання на картинку. Порожній рядок `""` — покаже плитку з назвою замість фото.
  Де взяти посилання: відкрий сторінку фільму (наприклад на themoviedb.org), клацни правою кнопкою по постеру → "Копіювати адресу зображення".
- `id` — необов'язково. Якщо не вказати, генерується автоматично з назви. Якщо колись зміниш `title` фільму, який уже має коментарі/реакції, вкажи `id` вручну (будь-яке унікальне слово латиницею), щоб не втратити прив'язані до нього коментарі.

Збережеш зміни (Commit changes) — усі сторінки оновляться самі протягом хвилини.

## Реакції та коментарі глядачів (Firebase)

На сторінці кожного фільму (`movie.html`) — емоджі-реакції (🔥❤️😂😢🤢) та коментарі глядачів. Оскільки GitHub Pages сам по собі нічого не зберігає, це працює через безкоштовний Firebase (Google).

Конфіг Firebase уже вставлено в `common.js` (в одному місці для всіх сторінок) — якщо колись знадобиться змінити проєкт, онови його там.

### Правила безпеки Firestore

У консолі Firebase: **Firestore Database → Rules**, встав:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /reactions/{movieId} {
      allow read: if true;
      allow write: if request.resource.data.keys().hasAny(['fire','heart','laugh','sad','sick']);

      match /comments/{commentId} {
        allow read: if true;
        allow create: if request.resource.data.text is string
                       && request.resource.data.text.size() > 0
                       && request.resource.data.text.size() < 500
                       && request.resource.data.name is string;
        allow update, delete: if false;
      }
    }
  }
}
```

Натисни **Publish**.

### Модерація

Коментарі не можна редагувати чи видаляти з сайту (навмисно, щоб ніхто не підчистив чужі). Видалити недоречний коментар: Firebase Console → Firestore Database → Data → колекція `reactions` → документ фільму → підколекція `comments` → видалити потрібний запис.

## Хостинг (GitHub Pages)

1. `github.com/new` → назви репозиторій → Public → Create repository (без README/gitignore/license)
2. У репозиторії: **Add file → Upload files** → залий усі файли з цієї папки → **Commit changes**
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main` / `root` → **Save**
4. Через хвилину сайт буде за адресою `https://<нік>.github.io/<репозиторій>/`

## Далі, якщо захочеш автоматизувати

Коли набридне редагувати вручну, `movies.json` можна дописувати автоматично через Streamer.bot: команда типу `!сьогодні <назва>` через GitHub API комітила б новий запис прямо в репозиторій. Скажи, якщо захочеш це зробити — налаштуємо окремо.
